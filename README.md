# 元龙因果链

（yl-causal-chain）

> 元龙因果链（Yuanlong Causal Chain）是一套以**事件**为认知基本粒子、以**因果拓扑**为世界观、以**观测者对贞**为唯一闭合标准的数据与推理体系。它不把世界看成一条单线的时间轴，而看成一张**可合并、可分支、可回环**的多因多果链网。

---

## 一、基本单元：事件

系统的认知基本粒子不是 `Token`，也不是 `click` / `scroll` 之类的动作谓词，而是中文意义上的**事件**。

- **可坍缩**为最简二元组骨架：**谁 | 做了什么**；
- **可扩张**为「时间、地点、人物、开始、冲突、结局」等复杂多元组的叙事表达；
- 显式或隐式**携带时间一维矢量**，时间有方向箭头。

事件的结构连「有 / 无」都相对观测者而言——被观测描述时会自动补全结构和实体。这种**相对性**，注定它包容了这个世界目前的表达方式。

---

## 二、数据结构：甲骨文的动作标签

链结构吸取自中国商代**甲骨文贞卜记事**的方式，以三个动作标签串联事件：

| 动作标签 | 含义 | 因缘标签 |
|:--|:--|:--|
| **贞** | 首发记录 | `因` |
| **又贞** | 持续观测、继续记录 | `因` |
| **对贞** | 结果确认 | `果` |

事件通过前后指针（`previous_ids` / `next_ids`）相连，形成**多因多果**的链网。贞—又贞—对贞**不是独立闭合单元**，可合并、分支、回环；即使只有单一节点也成立。

---

## 三、观测机制：视界、指针与望远镜

- **事件视界**：以焦点事件为中心、语义向量距离半径内的节点集合——既「聚焦」当前节点，又用「余光」扫语义相关节点。
- **因果指针**：沿前后指针移动观测中心，实现向前 / 向后 / 分支 / 合并 / 回环的移动，使观测者能「前后」看、兼「周围」看。
- **望远镜（`max_eyes`）**：调整事件视界的观测半径（建议 30–60 光年）。
- **因果虫洞**：无显式因果箭头、却被语义引力拉进视界的链外节点，是解释链间逻辑断裂的合适候选。
- **相事件**：为自洽或推导后续而假定 / 写入的虚拟事件枚举，因缘标签为 `相`。
- **势**：多个相事件在四维时空（语义距离三空间 + 时间代谢衰减 + 观测激活恢复）中的叠影对齐程度。

## 四、核心哲学：观测者主权

**观测者主权至上**是元龙因果链区别于一切客观因果系统的根本：

- **果无普适，对贞坍塌**——果由观测者鉴定，不脱离因果链单独评价；就连「因 / 相 / 果」的身份也是相对的，随观测者选认；
- 世界是意志主体在时间一维矢量上不断维护的**因果拓扑与能量守恒态**；脱离意志主体的世界，只是无序的相云；
- 系统的角色是**照亮**，不是判案。

---

## 五、理论层与运作层

元龙因果链分两层看：**理论层**是四个因果配平方程，作为物理层面的抽象（它们是**碳基生命智慧转述给硅基智慧的表达**，本文不展开其具体定义）；**运作层**是「三器」——在四方程理论之下，因果拓扑**怎么动**的运作方法。

**三器 = 干涉器 / 坍塌器 / 重构器**：

- **干涉器**——承担意志能量的定向传输与能量调节：析出事件粒子、结算能量增损、令果按意志方向坍塌。
- **坍塌器**——把一串旧事凝为最简果点二元组，删前案、多因多果重连，令长链归于平静（成见之形成）。
- **重构器**——从果回逆重构事件：乘愿再来、入世复生，把坠入地宫的旧叙事重新贞入、重接线纲。

> 三器不是三个并列的功能模块，而是**四方程理论下的三种运作方法**。至于「切片」，是事件粒子进入因果场的数据入口，不列于三器之中。

## 六、全维扩展

在「记」与「看」之外，体系还向下延展出两层：

1. **量化照亮 · ECM**：当链条出现逻辑断裂、常理性错误或能量配平失衡时，以元龙事件因果模型给出照亮指标（配平失衡量、照亮度、主体连贯度、暗物质候选）。**只照亮候选位，不替观测者判因果。**
2. **表达干涉**：因果链不仅「存」因果，还能「发」因果——由发射端（单源）与接收端（双源干涉）把果标签渲染为带极性、带强度的自然语言表达，并可据对方表达结算成见的增损回转。它是三器之「干涉器」在会话层的具体用器。

## 七、与传统因果推断的分野

| 维度 | 传统因果推断 | 元龙因果链 |
|:--|:--|:--|
| 认知基本粒子 | Token / 文档 / 节点 | **事件**（谁\|做了什么 + 时间矢量） |
| 世界观 | 静态关系图 | 随观测权重动态重排的**因果场** |
| 观测者角色 | 排除主观影响 | **最终裁决者**（观测者主权） |
| 果的性质 | 追求普适、可验证 | **无普适，对贞坍塌** |
| 系统的位置 | 因果裁判官 | **照亮者**，不越位 |

> 传统在问：「怎样让模型更符合因果？」
> 元龙在问：「为什么还要让模型在 Token 世界里理解因果？」

## 八、原则总纲

1. **观测者主权至上** —— 一切描述判定，以观测者为参照系。
2. **相对性包容** —— 事件结构随表达自动补全，不预设唯一正确形态。
3. **多因多果** —— 链网可合并、分支、回环，不强迫闭合。
4. **照亮不判案** —— 量化只给候选位，判定归观测者对贞。
5. **知止** —— 自洽即停；不自洽则明示缺失或给出相事件候选。
